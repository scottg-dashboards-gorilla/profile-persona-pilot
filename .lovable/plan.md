# Connect Home to a real review cycle

## What will change
- Add a Review Cycle page showing the active cycle’s start and end dates, goals, current stage, completion percentage, and role-specific next actions.
- Make every Home stage open a specific task: create/submit goals, write employee input, draft manager feedback and scores, approve department questions, approve pay, release the outcome, or acknowledge it.
- Add direct links into the existing Admin panel tabs, including Review Questions, and retain all current permissions and confidentiality rules.
- Clarify Access and Audit log pages with actionable empty states and links where the data shows unresolved work.
